# 修改电脑时区与区域

先识别系统，只打开对应参考：[macOS](references/macos.md)、[Windows](references/windows.md)、[Linux](references/linux.md)。认不出系统就停，不套用另一份里的命令。

用户只要求时区时，不改语言、输入法或浏览器。只查询出口或当前设置时只报告，不建回滚、不写配置。

## 选择目标

用户指定的城市或国家优先。只有用户要求按出口对齐时，才查询现有出口，例如 `curl -4 -fsS https://ipinfo.io/json`；用户指定 IP 则查该 IP。不改代理、路由或 DNS。记录 IP、国家、城市和时区。该系统的时区列表里没有这个时区，或地理数据不确定时，说明缺口，不猜城市。

多语言，或已经有输入法时，目标语言放在第一位，其余保留。键盘不能只按 IP 推断。

确有修改请求时列出本轮要改的项，沿用已有授权，不重复确认。

## 修改与回滚

每次修改前用 `mktemp -d` 建权限 700 的新目录，保存将改文件的原内容、权限和「原先不存在」。不覆盖旧回滚。恢复时，原先不存在的文件应删除，而不是写回一份默认内容。

时区 ID 必须先在该系统的列表里找到。日期、数字、货币、度量从目标区域读取，不把美国设置套到其他国家。

可以关闭自动时区，避免定位覆盖刚写上的时区。不因为改区域而更换 NTP 源，也不手改时钟。要探测的时间服务器域名若解析到 `198.18.0.0/15`，停止该源，不改 DNS、不手设时间。一个源不可用不能说明整个系统没同步；读不到实际状态就写「未验证」。

只在用户要求包含应用或浏览器语言，且该浏览器没有运行时，才改浏览器语言。不覆盖其他策略。浏览器运行中不写它的偏好文件。

## 验收

读回时区、语言、区域和本轮改过的项。报告回滚目录，以及没做或要等重新登录才生效的项。不重启图形会话，不替用户结束浏览器。新登录前不宣称界面语言已经切换。
