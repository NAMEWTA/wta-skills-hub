# 按代理出口对齐 Ubuntu 区域

环境要求：已提供 systemd Ubuntu 操作参考；GNOME 桌面项需要可确认的目标用户及会话。

在用户明确要求的范围内修改主机区域，命令、环境检查和回滚见 [Ubuntu 区域参考](references/ubuntu-region.md)。用户只要求时区时，不扩展到语言、输入法或浏览器。

## 读取与选择

1. 核实 systemd Ubuntu 与必要工具。其他平台不照搬命令；说明当前技能支持范围。
2. 用现有出口查询位置，例如 `curl -4 -fsS https://ipinfo.io/json`；用户指定 IP 则查该 IP。不改代理、路由或 DNS。
3. 记录返回的 IP、国家、城市和 IANA 时区，并用本机时区数据库校验。无时区、地理数据不确定或出口不匹配时说明缺口，不猜城市。
4. 多语言国家或用户已有明确语言偏好时，先确定要保留/选择的语言。键盘不能仅由 IP 强制推断；保留已有输入法。
5. 只查询出口时只报告。确有修改请求时列出本轮目标并沿用已有授权，不额外要求重复确认。

## 修改与回滚

- 每次修改前创建唯一且不覆盖的回滚记录，保存所有将修改文件的原内容、存在状态及相关设置。系统文件、账户、桌面、浏览器策略均不能遗漏。
- 时区使用 IANA 名称；格式从选定 UTF-8 locale 读取，不把美国设置应用到其他国家。
- 桌面项先确认用户、session bus、schema 与键值；无图形会话时跳过会话设置，不猜用户、不宣称桌面已修改。
- 只在请求包含应用语言时调整浏览器语言；不得覆盖其他管理策略。浏览器运行中不写 Preferences。
- NTP 只检查并报告，不因为调整区域而自动更换时间源。候选域名返回 `198.18.0.0/15` 时停止该源相关操作，不改 DNS 或手动设时；实际同步状态另行读取，不能由单个源推断全局失效。

## 验收

读回时区、locale、键盘与本轮修改项，用新 locale 下的 libc 检查日期、数字和货币；报告回滚记录位置及未完成项。新登录会话前不宣称桌面或当前 shell 语言已生效，不重启显示服务或终止浏览器。
