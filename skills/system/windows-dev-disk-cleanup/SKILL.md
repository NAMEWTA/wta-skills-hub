# Windows 开发机磁盘清理

环境要求：面向 Windows/PowerShell；部分已授权系统操作需要管理员权限。

用工作区的 `清理清单.md` 记录候选、用户决定、执行状态与实测变化；用户指定其他文件时遵从。阶段命令和发现方法见 [清理工作流](references/windows-cleanup-workflow.md)。

## 判断授权与范围

- 审计/规划请求只检查和报告，不删文件、清缓存、卸载、停进程、改环境或安排重启任务。
- 用户已批准的清单项可直接执行，不重复请求相同授权。新候选保留为待确认，不扩大已批准范围。
- 每个目标落到确切路径、产品 ID、包名或功能名；记录所有者、估计大小、决定、前置条件和实际状态。保留稳定编号及历史，不覆盖旧决定。
- 大范围分拣可分批询问；默认每批 5 项只是交互建议，用户指定批量时优先。

## 执行边界

- 开始前核实管理员权限是否必要、路径与所有权是否仍匹配清单；区分缓存、项目、配置、凭据、下载和用户数据。
- 优先官方卸载器或包管理器；不使用宽泛 glob。注册表残留只有证明对应产品已不存在且过期后才删除。
- 拆旧运行时之前，验证要保留的替代工具链。不得删除承载当前智能体或活动进程的运行时映像；物理删除留到已切换的新会话。
- WinSxS/ResetBase、pagefile、WinRE、更新数据及还原点属于独立决定，不包含在普通磁盘清理授权中。
- 目标锁定、servicing 进行中、共享依赖不明、保留工具验证失败或现场与清单矛盾时，停止受影响项，不强制解锁或扩大删除范围。

## 完成标准

按小阶段测量卷可用空间，区分目录估算与实际释放量；核对保留的工具、项目、环境变量和应用状态。将成功、失败、保留项、锁定残留和待重启事项写回清单。

不自动重启；受阻项保持未完成。仅清理本轮自行创建且不再需要的临时文件，保留清单与用户需要的证据。
