# 照片精准编辑与美化

以用户照片为基准，把「改哪里、怎样改、保留什么」写清楚，再使用当前环境可用的图像编辑工具完成任务。默认追求自然、克制、保留人物辨识度。只有用户指定创意玩法、换背景、摄影调色或画幅变化时，才扩展到对应的风格、环境或构图。

## 输入与工具

- 先查看实际原图。确认哪张是底图、哪张提供人物/宠物身份、哪张只供风格或构图参考；记录文件或附件与图号的映射。文章中的「图片」占位、文字描述和看不到的附件都不算已提供原图。
- 用户要求直接修图且图片已齐备时，直接执行。仅在缺原图、目标无法区分或缺少必要参考时补问；普通的「自然修一下」采用轻度修饰，不要求用户填写参数表。
- 用户仅要提示词时，交付可复制的编辑指令，不调用出图工具。缺图时可先提供带明确变量的模板，但不能声称已检查或修好照片。
- 使用宿主实际提供、支持参考图编辑的工具；调用前核实图片数量、蒙版、尺寸等可用参数。工具支持蒙版或选区时优先用于局部编辑，不杜撰接口字段。遵守该工具对本地路径、附件和图片返回方式的约定。
- 没有可用图像编辑工具时，说明当前只能整理提示词，并交付完整提示词及素材顺序；不能把文字方案当作成片。无需绑定特定供应商或强制安装另一项技能。
- 模型名称、输出尺寸以实际工具能力与返回信息为准。不能根据文章、提示词或画面风格认定使用了某个版本，也不能把「高清/4K」措辞当作分辨率保证。

## 选择编辑范围

| 范围 | 适用任务 | 保留重点 |
|---|---|---|
| 局部修图（默认） | 去游客、去杂物、整理发丝、局部美颜、主体贴纸、文字涂鸦 | 修改区外的人物、物体位置、透视、构图和照片风格 |
| 整体影调 | 曝光、白平衡、色彩、清晰度与降噪 | 场景内容、人物身份和几何结构；允许光色全局变化 |
| 创意重构 | 拍立得公仔、明信片、旅行拼贴、演唱会新姿态 | 用户指定的人物辨识度、地标特征、场景关系；允许明确要求的风格和构图变化 |

「让照片好看一点」默认只改善影调和可见的小瑕疵，不自动瘦脸、扩大眼睛、换发型、换背景或改变身材。用户明确要求的造型和轮廓调整可以加入修改清单，避免把个人审美套到每张脸上。

换背景、扩图、室内软装，以及日夜、季节或天空变化，只有用户明确提出时才做。这些任务保留人物身份、商品文字与件数，或原机位和结构；被点名的区域可以改变光色。不要同时要求整张照片的颜色和内容完全不变。

## 组织并执行编辑

1. **定位目标。** 用「左下角第一把椅子」「右侧穿红衣的路人」等可辨识位置描述，优先采用用户标注。多张图时写明每张图的用途；风格图不提供人物身份。
2. **形成修改清单。** 区分要改的区域与要保留的区域。独立、兼容的小修改尽量一次完成；造型重构和精细修复需要分步时，每步检查后再继续。
3. **编写提示词。** 从对应模板提取所需部分，将 `{{变量}}` 替换为用户要求或原图可见事实，删除不适用句子。顺序采用「底图/参考职责 → 目标区域 → 编辑动作和强度 → 保留项 → 材质/光影 → 输出要求」。整体调光不同时要求所有颜色不变；创意重构不同时要求整张照片完全不变。
4. **调用并保留原图。** 编辑请求必须带上底图与必要参考，避免退化为凭描述重画。沿用原比例，除非玩法或用户要求改版式；指定尺寸用受支持参数落实。保存为新文件或工具提供的新输出，不覆盖源照片。
5. **检查再交付。** 查看实际结果，对照原图及本次修改清单；发现问题时只修复具体缺陷。出现累积噪点、脏色或人物漂移，回到原图或最近合格版本，合并已确认的修改重新编辑。同一缺陷连续两次修正仍无改善时，保留最佳版本并说明未解决处，不无限重试。

局部编辑提示词骨架：

```text
以{{底图}}为唯一场景基准。仅修改{{明确目标区域}}：{{编辑动作、程度及期望效果}}。
保留{{人物身份、姿态、服装、建筑结构及其他重要细节}}；修改区域外的构图、位置和透视保持原样。
新内容的光向、色温、阴影、纹理与原照片一致，边缘自然衔接。{{本任务特有的限制}}
输出{{比例与支持的尺寸要求}}的编辑成片。
```

如用户要求未编辑区域逐像素不变，仅凭提示词不能承诺达成。当前工具支持精确蒙版/局部回贴时采用并验证；不具备这种能力时说明边界，不把视觉相似说成像素一致。

## 成片检查与交付

- **编辑命中：** 目标确实改变，游客/杂物没有残影；需要保留的同伴、倒影和场景细节没有被误删。
- **人物与结构：** 脸仍有原有辨识度，皮肤有纹理；手指、四肢、头发、建筑直线、贴纸边缘和遮挡关系合理。
- **画质与融合：** 肤色自然，光影一致，没有新增涂抹感、光晕、黑斑或明显接缝；不要为了降噪抹掉真实细节。
- **专项约束：** 按所读玩法或参考检查贴纸数量、底色、标签、画幅、文字拼写、留白和主体遮挡；有完整文字要求时逐字核对，无法实现则如实说明。
- **输出证据：** 提供实际图片或文件链接，简要说明改动及尚存问题。报告尺寸前读取实际结果；未实测不宣称无损、4K 或像素完全一致。文字提示词交付应包含必要素材及其顺序。
