# 安装设计与恢复

## 数据流与边界

`bin/wta-skills-hub.mjs` → 编译后的 `dist/cli.js` → 包内 catalog → Clack 选择 → `planInstall` → 预览和确认 → `applyInstall` → 文件读回。

TypeScript 严格模式；Citty 统一参数与帮助定义，Node 的严格参数解析保留重复 `--skill`/`--agent` 并拒绝未知选项；不依赖任意字符串拼接 shell。Node 内置 test runner 保留原测试基础，避免只为安装菜单增加第二套测试框架。

本安装器不会请求账户凭证、执行技能脚本、修改 shell profile、修改 `.codex/config.toml`、写 Claude settings、创建云端 Bot 或启动 Agent。包安装到 npm 缓存和技能复制是两个阶段：第一次 `npx` 可以联网；复制阶段只读包内资源。

## 路径、内容与适配

只支持当前用户和明确项目，真实化可信 HOME/项目锚点后拒绝其下的符号链接、junction 或非目录目标。来源资源也拒绝链接、设备和 socket。安装采用真实复制，不把指向临时 npx 缓存的链接留给用户。自定义 `CLAUDE_CONFIG_DIR` 不做猜测；遇到非默认全局配置明确拒绝。

Codex 和通用选项共享 `.agents/skills`；生成去重后的目的目录。Claude 单独使用 `.claude/skills`。对 Herdr 这类声明 `metadata.wta-explicit-only: "true"` 的技能，Claude 副本插入 `disable-model-invocation: true`，通用原件保持规范字段；Codex 策略保存在技能自己的 `agents/openai.yaml`。通用消费者不一定实现显式调用元数据，因此正文也必须要求用户明确选择 Herdr。

SHA-256 覆盖排序后的文件相对路径、字节长度和内容，包括安装目录中额外的用户文件；不覆盖权限位、空目录和安装器自己的标记文件。相同内容不会重写，因此也不会“修复”用户自定义权限。源缓存和 `.git` 等开发残留不复制；嵌套快照模板作为普通资源保留。

标记仅位于每个技能的 `.wta-skills-hub.json`。不写 `.claude/skills/manifest.json`，避免占用客户端的特殊文件名。

## 事务语义

默认遇到任一内容冲突阻止整个安装。显式 skip 只安装缺失项；显式 backup 保存完整旧目录后替换。多目标按固定顺序取得 `.wta-skills-hub.lock`，发现已有锁立即失败，不抢锁。所有技能先暂存到 `.agents/.wta-stage-*` 或 `.claude/.wta-stage-*`，不暴露为可扫描技能。

预览后、提交前重新校验内容，拒绝覆盖期间出现的新修改。每个技能通过 rename 提交、再读回校验；失败时逆序回滚。备份保存在锚点下 `.wta-skills-hub/backups`，不位于 `.agents/skills` 或 `.claude/skills` 的扫描子树中。原目录不存在时回滚会移除本次新建项，只清理安装器创建的空目录。

这是**正常进程异常的批次回滚**，不是断电一致性数据库，也不是多目录瞬时原子可见性。跨文件系统 rename 会失败并进入回滚，不通过复制后删除降级。恶意同 UID 并发进程的所有 TOCTOU 攻击不在本工具的安全隔离保证内；不要把技能目录设为不可信多人共享写入目录。

POSIX 新建目录为 0700、文件 0600，保留所有者可执行位为 0700。Windows `chmod` 不提供等价 ACL 隔离：目标继承目录 ACL，需由用户确保 HOME/项目/备份仅对适当账户可读写。

## 手工恢复

首先关闭相关 AI 会话，确认没有同一目标的安装进程。查看错误中的**准确目标和 backup 路径**，先读备份，不执行里面的脚本。正常成功的替换也保留备份，直到用户自行确认可删除。

需要还原时，将当前新技能移到扫描目录以外的隔离目录，保留所有后续编辑；再把完整旧备份目录移动回原技能位置。逐文件比较后重新打开客户端。不要把两个版本的目录都放在 skills 内，也不要只覆盖部分文件留下新旧混合版本。

若强杀/断电后发现 `.wta-skills-hub.lock` 或 `.wta-stage-*`，先根据锁内 PID 和批次记录确认没有活动进程、检查目标/备份是否完整，再手工清理该次锁和暂存。不要删除所有锁或历史备份来“修复”。出现权限拒绝、跨设备错误或不确定的内容差异时停止并保留现场。

## 测试范围

单元与离线集成覆盖选择、真实取消符号、重复参数、无 TTY、路径去重、符号链接拒绝、同名保护、备份位置、失败回滚、外部编辑保护、排他锁以及所有 14 个技能的独立安装。真实 tarball smoke 与新 npm 生产依赖安装分别执行和记录。它们不验证客户端实际发现、模型正确触发、云端权限、原生桌面变更或网络产品性能。
